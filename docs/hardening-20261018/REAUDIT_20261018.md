## Findings and minimal remedies

1. **Queued usage metadata reads a pooled Gin context (P1, existing official-origin gap).** Twelve asynchronous callbacks resolved `ChannelUsageFields` after queue submission, and Alpha search read `PricingAt` in its callback. Gin can reuse `c.Request` for another request; model/pricing metadata can then come from the wrong request. Snapshot the needed scalar/value data before submission, without copying the entire context or changing pricing. Evidence: [Gin's official guidance](https://gin-gonic.com/en/docs/middleware/goroutines-inside-a-middleware/) and [Gin issue 3931](https://github.com/gin-gonic/gin/issues/3931). The helper is identical at the official comparison; restored-fork blame is not proof of custom ownership. Deterministic tests hold the billing worker, replace the completed request, then inspect usage metadata.
2. **Converted SSE parsing rejects valid multiline events (P2, candidate regression).** Processing each `data:` line as complete JSON rejects a trailing empty data line that merely adds JSON whitespace. Reuse the existing frame parser, retain data-field presence, bound aggregate frame bytes, and decode completed events. A present-empty error event is distinct from an event with no data field. [WHATWG SSE](https://html.spec.whatwg.org/multipage/server-sent-events.html#event-stream-interpretation) supports these framing rules. Existing final-EOF-frame and immediate standalone DONE compatibility is retained; this is not a claim of complete browser EventSource conformance.
3. **Wokey multipart structured `images` bypasses the existing pre-forward image projection (P1, candidate regression).** The new scalar preservation path could add an image after the existing multipart moderation parser had observed only the prompt. Reject that unsupported multipart field before upstream forwarding; keep the established image-file and JSON routes. Tests cover typed rejection, no upstream call, handler 400 mapping, and valid JSON preservation. The handler test covers service plus error mapper, not a complete routed moderation deployment.
4. **Withheld malformed raw-CC data can create a failed-request charge (P1, candidate regression).** The new parser-error branch returned a nonnil zero-usage result before the no-output guard; per-request pricing can charge it. Return nil accounting result only when no output was released and no usage observed, retaining the same nonretry error. Preserve partial/metered billing and cancellation handling. Standard-mode mock tests must assert actual billing-command counts and amounts, not merely HTTP status.
5. **Images total-budget expiry can penalize the last healthy lane (P2, existing custom logic).** A request-wide budget exhausted across earlier attempts is not the last account's independent attempt timeout. Use the actual image request-budget context for the production health guard; preserve independent attempt timeout penalties and calibration behavior.
6. **Choice-terminal tracking adds quadratic work (P2, candidate regression).** Rescanning the entire observed-choice map after every chunk makes sequential distinct indexes quadratic. Maintain unfinished count incrementally and constrain production indexes to the count in the final outbound request (default one); avoid arbitrary new provider limits or preallocation from untrusted counts. Preserve the existing policy for completion of observed choices.
