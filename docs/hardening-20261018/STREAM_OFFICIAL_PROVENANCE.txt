LOCAL ADAPTATION BOUNDARY
The new bounded synchronous scanner is our narrowly scoped implementation, not an official merged patch. It is limited to the affected Chat conversion/raw readers. It preserves configured idle=0 for connected clients, applies an absolute five-second cancellation/write-failure drain, preserves the caller's deadline, and retains cancellation ownership through the response body. Existing native Responses users and global detachUpstreamContext semantics are unchanged. Extending the shared native line pump would change unrelated callers and still require reader lifecycle work; the synchronous scanner introduces no scanner goroutine and keeps parsing/client writes on the request goroutine.

Terminal evidence is separate from usage. Valid finish_reason plus clean EOF remains accepted. Invalid finish reasons, malformed JSON, explicit JSON or SSE error events, interrupted reads, and unfinished observed raw multi-choice streams cannot synthesize completion. Converted Messages/Responses adapters explicitly reject multi-choice input that their single-response protocol cannot faithfully represent. Raw multi-choice streams remain supported when every observed choice finishes.

Tests use local synthetic bodies, pipes and handler fakes only. No production configuration, deployment, push, credentials, or paid provider requests are involved. Final test results are recorded separately; this provenance record is not a claim that tests have passed.

FORK-OWNED SMART ROUTER CORRECTION
backend/internal/service/smart_router_runtime.go is absent from official main and was introduced by fork commit ab4fa541c (Restore Phase 2 Smart Router adaptation). Its text reporter ran before handler cancellation guards, so a canceled client with an incomplete stream could reduce provider health and trigger cooldown. The minimal correction passes the request context at the two production text-report call sites and centrally excludes canceled requests / ClientDisconnect results. Real upstream failures for still-connected clients retain existing penalties. No routing algorithm, weights, persistent schema, image/compact reporting, or unrelated native Responses reader changes were made.
