# Smart Router 图片策略拒绝与有限切线开发文档

## 目标

只在 `backend/internal/smartrouter/core` 内优化图片调度，处理上游偶发的
`400 content_policy_violation` 或同类策略拒绝，同时保持现有聊天、Responses、
compact、429、尺寸路由、FIFO 恢复和凌晨 4 点校准不变。

本模块不修改 Prompt，不绕过上游安全策略，不永久关闭账号，也不修改数据库中的
原始价格优先级或 `schedulable` 状态。

## 已完成且保持不变

以下能力已经在当前代码中实现，本次不重写：

- `image_generation` 与 `image_edit` 分离维护健康状态和失败计数。
- 502/503/504/524、超时、网络错误使用软冷却，账号仍保留为最后候选。
- 图片连续失败三次后进入 `base_priority + 30` 的 FIFO 恢复队列；之后每三次失败再加 30。
- 4 点上海时间校准成功后恢复原始优先级，失败继续留在恢复队列。
- 1K/2K/4K 尺寸专用线路优先，专用线路失败后回退通用线路。
- 同一源组隔离、图片总预算、单次尝试上限和半开探测。
- 图片 429 使用请求级指数退避，不把一次并发限制直接当成线路永久故障。
- compact 使用独立的 `responses_compact` 健康维度，不与普通聊天或生图串用。
- 新的 active、可调度、模型和能力声明正确的线路自动进入候选。
- 上游错误状态和摘要保留，不把所有错误粗暴改成 502。

## 本次实现：图片策略拒绝临时软跳过

### 触发条件

只有同时满足以下条件才触发：

1. Smart Router 收到 `FailureContentRejected`；
2. 能力是 `image_generation` 或 `image_edit`。

聊天、Responses、compact 和普通参数错误不会触发本策略。

### 行为

- 默认记忆 10 分钟。
- 在有效期内给该 lane 增加临时优先级惩罚 `+30`。
- 惩罚只通过 `LaneSnapshot.PriorityPenalty` 生效，原始 priority 不变。
- 不增加健康惩罚，不创建 FIFO 恢复槽，不改账号开关，不写账号表。
- Smart Router 下一次排序会优先使用其他满足能力、模型、尺寸和并发条件的 lane。
- 如果没有其他候选，仍允许它作为最后候选，避免“所有线路都不可用”。
- 同一 lane 成功后立即清除临时记忆；到期后自动清除。
- 4 点校准成功也会清除临时记忆。

默认值由 `HealthPolicy` 提供：

```text
PolicyRejectCooldown = 10m
PolicyRejectPriorityPenalty = 30
```

### 重要边界

当前图片 handler 收到上游 400 后会结束本次 HTTP 请求；因此只改 Smart Router
core 不能让同一个已经返回 400 的请求在 handler 内继续发送第二条线路。
本次实现选择可实际生效且范围最小的方案：让下一次请求避开刚刚策略拒绝的 lane，
而不是伪造同请求切线。若未来需要同请求切线，必须另行修改图片适配层的 400
处理契约，并增加重复计费与幂等保护，本次不包含。

## 与现有恢复机制的关系

策略拒绝软跳过与健康降权是两个独立维度：

```text
策略拒绝  -> 仅图片、10 分钟、PriorityPenalty +30、无永久状态
上游抖动  -> 软冷却、健康惩罚、图片三次失败后 FIFO +30
4 点校准   -> 对被降权/冷却的线路做真实探测，成功后恢复
```

因此，策略拒绝不会把本来健康的线路错误推进到 `P+30/P+60`；而真正的 502、
超时、网络错误仍按既有健康策略处理。

## 测试要求

Smart Router core 至少覆盖：

- 图片策略拒绝产生 10 分钟临时惩罚；
- 原始 priority、健康惩罚、恢复优先级和账号状态不变；
- 10 分钟到期后恢复正常排序；
- 同一图片 lane 成功后立即清除；
- chat/Responses/compact 的策略拒绝不受影响；
- 既有图片 FIFO、4 点校准、429、尺寸专用线路测试继续通过。

## 部署与升级

该改动属于 Go 二进制代码，不能只改数据库配置使其生效。生产更新采用热替换
容器内二进制，不重建镜像；构建必须带 `-tags embed`，否则会丢失嵌入的默认前端
资源。更新前保存当前二进制和校验值，更新后检查 `/health`、登录页和 Smart Router
进程状态。

## 不在本模块处理

- 改写用户 Prompt 或尝试规避 OpenAI 安全策略。
- 把策略拒绝伪装成成功。
- 将所有 400 都改成 failover。
- 修改下游 V3 的视觉质量重试逻辑。
- 修改 compact 请求格式或上游模型能力。
- 增加新的数据库表或账号配置字段。
