# Security dependency refresh (2026-11-08)

This change addresses the existing draft branch's failing dependency scan. It does
not change the Native Harness protocol or authorize production deployment.

## Changes

- Go 1.27.3 across module, CI assertions, and all three Docker build definitions.
- brotli 1.2.7, klauspost/compress 1.20.2, and x/net 0.62.0, plus their minimum
  Go module graph upgrades. Checksums regenerated by Go modules.
- DOMPurify 3.4.17; transitive follow-redirects 1.16.2 and
  decode-uri-component 0.5.1.
- Vue I18n and its message compiler 11.4.14. The vulnerable 9.14.5 line has no
  reported patched 9.x version. The app already uses composition mode; a runtime
  dynamic-locale regression now covers interpolation, plural selection, locale
  switching and fallback. All locale strings are compiled in the critical suite.
- Node 22 minimum for the frontend, matching Vue I18n's declared engine; CI uses
  Node 22. Existing Docker Node 24 builds already satisfy this requirement.

The pnpm 9 lockfile preserves all unrelated resolutions, including the official
SheetJS archive's existing SHA-512 integrity. No audit exceptions were added.

## Scope of scan results

The local production npm audit after these changes has zero high/critical
advisories. KaTeX retains a low-severity existing-prototype-pollution prerequisite
advisory; this is not a claim of zero advisories.

Go symbol/package analysis reports zero reachable/imported vulnerable packages.
The required x/crypto module still carries GO-2026-5932 for its unmaintained
openpgp package, which this application does not import or call. No exception or
scan suppression was introduced. Exact-commit CI remains the release gate.

The first unbounded cloud Go compilation exceeded memory. The bounded retry
uses the existing CI-compatible GOMAXPROCS/GOFLAGS/GOMEMLIMIT approach; a resource
failure is not counted as a successful test.
