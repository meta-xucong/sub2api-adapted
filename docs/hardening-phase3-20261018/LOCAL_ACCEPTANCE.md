# 本地真实测试交接模板

本文件在候选提交冻结后使用。具体 SHA、PR 与 CI 见最终执行收据；不要用阶段二 ff27dd9c 的报告替代阶段三运行结果。

## 当前离线交付路径

本轮尚未上传GitHub。先按交付包中的HANDOFF，用bundle验证、fetch到新的本地分支，再建立独立worktree；不依赖不存在的远端cloud分支。核对包内最终HEAD与受测代码ef5187，后续仅文档提交。下面远端同步步骤仅适用于将来获准发布后，不是当前已发生的动作。

## 发布后再同步到隔离目录

1. 确认远端仓库 `meta-xucong/sub2api-adapted` 和最终指定分支/SHA。
2. 保留本地主工作区和未提交文件。只 fetch；在新的独立 worktree 检出指定 SHA，不执行 reset --hard、clean 或覆盖原配置。
3. 使用 repo 锁定的 Go、Node、pnpm 和锁文件。不要为通过测试改版本、断言或跳过项。
4. 先在本地独立 PostgreSQL/Redis 及空数据卷运行迁移和测试。绝不连接生产库、共享生产 Redis 或挂载生产备份为可写目录。

## 自动验收

- 原始 `make test-unit`、`make test-integration`、前端测试与 typecheck。
- 原始 golangci-lint；查看实际执行项与跳过项。不能将 repository TestMain 因缺 Docker 提前退出的包 pass 当作已执行数据库测试。
- 真实浏览器验证媒体预览 CSP：允许的媒体源可播放、未授权媒体源被阻止、自定义 CSP 保留管理员策略。
- 完整构建及启动健康检查；构建和 `--version` 不能替代应用启动。

## 本轮重点场景

1. 订阅请求保留路由计价决策；余额模式、取消与释放不回退。
2. 三种 Images 链路：失败无产物无用量、失败正数用量、部分产物、成功和切号。分别核对 token/image/按次计价；重试尝试不可重复结算。Mock 金额与真实结算必须分开记录。
3. 自定义语音：A/B 两个下游用户、同一上游账号及不同上游账号。新建、列表、详情、修改、删除、音频读取、TTS、Realtime 均核查隔离；换 API key 不应换用户归属，撤销组权限须生效。旧未知 ID 不会自动归属任何用户。
4. 自定义语音创建/修改/删除时断开客户端；确认服务端在有界时间内写入归属或墓碑。上游成功、本地 SQL 故障仍是分布式不确定状态，记录故障并人工对账，不自动再创建。
5. Wokey 视频引用 exact 8 MiB 及超限、换行 base64、percent 编码；观察内存峰值而不只看错误码。
6. HTTP/1 与 HTTP/2 实际协商、代理、PING 及各自空闲时间；保留配置的 H1/H2 差异。

## 迁移、旧资源与回滚

247 是新增归属表，不从现有上游共享库存推测所有者。部署之前必须确认是否存在旧 custom voices。若存在，收集可信的用户创建记录、上游账号和资源 ID，制定人工审核的归属恢复步骤；没有证据的资源不能开放给任意租户。此版本不提供用户自助认领未知 ID 的接口。

仅回退应用二进制并不能安全撤回语音权限治理：旧版本可再次直通共享上游资源。保留新增表和墓碑，避免数据丢失；若必须回滚，应先评估是否隔离相关接口，实际生产配置变更须另行批准。

上游账号 ID 必须继续代表同一上游资源命名空间。管理员如果更换了该记录的凭据主体或 origin，应新建账号并评估旧资源迁移，不能假设新主体有同一批 voice ID。自动 token 更新和主体替换不是同一个概念。

## 真实消费门槛

真实 Provider 调用、真实金额、付费生图/生视频/语音及 VPS 切换，需要明确目标和额度。先小样本、独立测试账号、测试数据和账单对账，之后再评估生产切换。源码审计和 mock 成功不代替这些证据。

在线 npm/Go 扫描尚未获批准时保留未完成状态；不得禁用工作流来获得绿色标记。公开推送的现有自动 CI 会触发这些扫描，因此需取得相应确认后再推送。
