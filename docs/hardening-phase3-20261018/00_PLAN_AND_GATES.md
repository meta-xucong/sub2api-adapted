## lint 兼容性决策

旧记录有 107 个报告位置，其中 1 个为 SA4009 关联位置。逐个五行上下文均能在原始 main 找到；仅 29 个在记录的官方合并父提交中也精确匹配，不把其余都称为官方遗留。

HTTP/2 客户端使用 Go 1.27 原生 HTTP2Config 配置相同 PING 参数，保持 HTTP/1 回退及各模式选择。服务端 x/net wrapper 的独立 H2 IdleTimeout 在原生 HTTP2Config 中没有等价字段，直接迁移将改变 H1 或 H2 超时。因此保留兼容 wrapper，仅在确切使用行标明 SA1019 兼容性例外。9 处兼容注释使用 golangci-lint 支持的逐行 `//nolint:staticcheck // SA1019: <具体兼容理由>` 语法，保留每处原有理由，不增加文件级或全局排除；GoAwayError 类型匹配同理保留，覆盖 Error 文本隐藏原因的包装器。没有全局关闭 staticcheck/gosec，也不把保留的弃用标记称为修复了功能漏洞。要求真实 loopback 协议回归覆盖 H1/H2 及独立超时。

官方类型参考：https://pkg.go.dev/net/http#HTTP2Config 、 https://pkg.go.dev/golang.org/x/net/http2 。实现依据包括当前仓库锁定 x/net v0.60.0 `server_wrap.go`、`transport_wrap.go`，以及 Go 1.27.2 源码；不凭较旧 API 印象迁移。

## 来源与阶段二决定的变化

阶段二将 voice 所有权列为延期，原因是未发现 Sub2API 官方对应的隔离修复。本次用户明确要求继续解决已列出的代码缺口，因此提供单独可审查的持久化权限补丁；这不是声称它属于用户原有自建代码，也不是声称官方已发布相同修复。xAI 官方文档明确 custom voices 属于上游 team，而本站账号共享不能等价于下游用户共享。代码中的跨用户访问可由隔离 fake-provider 复现；修复原则参考 OWASP API1:2023 的对象级授权要求：https://api-security.owasp.org/editions/2023/en/0xa1-broken-object-level-authorization/ 。这是一类权威公开安全原则，不是 Sub2API 专属公告或 CVE。

IP 默认值仍遵循官方已知兼容选择（官方讨论 https://github.com/Wei-Shaw/sub2api/issues/6112）。本轮不把用户授权代码修复解释为授权改变线上安全设置；验收必须明确选择 secure false +准确可信代理或保留兼容模式并限制源站访问。不能声称兼容模式抵御伪造原始转发头。已有 false/true 的历史来源无法从值本身证明，禁止自动重写历史选择来伪装完成迁移。
